# NOMAD entry in the EOSC Finland service catalogue

Catalogue: [EOSC Finland - Services and resources](https://research.csc.fi/eosc-services/), maintained by CSC - IT Center for Science.

The catalogue metadata are managed on the Eduuni wiki: [Service Description NOMAD](https://wiki.eduuni.fi/spaces/csctuha/pages/854139826/Service+Description+NOMAD?focusedCommentId=867697151#comment-867697151). Ahmed Mansour ([amansour@physik.hu-berin.de](mailto:amansour@physik.hu-berin.de)) has access to edit the page.

[NOMAD_metadata.md](NOMAD_metadata.md) is the local copy of the agreed content, including the English and Finnish text and the form's field guidance. Keep it synchronized with the wiki.

## Instructions for updating the entry

1. Update the metadata on the Eduuni wiki page linked above using an account with editing access.
2. After editing the wiki, send a follow-up email to both **Lassi Lager** (`lassi.lager@csc.fi`) and **Jessica Parland-von Essen** (`jessica.parland-vonessen@csc.fi`). Include a link to the wiki page and a summary of the changes so they can be reflected in the catalogue.
3. Update [NOMAD_metadata.md](NOMAD_metadata.md) to match the agreed wiki content.
4. After publication, verify the displayed content and links against the metadata file, record the direct catalogue entry URL here, and update the date in the [main README](../../README.md).

Publication status and a direct catalogue entry URL have not yet been recorded in this repository.
